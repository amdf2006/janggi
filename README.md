# 장기 (將棋) — 1단계

컴퓨터와 18급~9단 실력으로 두는 한국 장기 웹 게임.

## 배포 (Vercel)
1. 이 폴더 전체를 GitHub 저장소에 올리고 Vercel에서 Import → Framework Preset: **Other** → Deploy
   (빌드 명령 없음. 정적 사이트)
2. `vercel.json`이 엔진에 필요한 보안 헤더(COOP/COEP)를 자동으로 붙입니다. 이 파일을 빼면 엔진이 안 돕니다.

## 내 PC에서 테스트
```
npx serve .
```
`serve.json`이 같은 헤더를 붙여줍니다. 파일을 더블클릭해서 열면(`file://`) 엔진이 동작하지 않습니다.

## 구조
- `index.html`, `css/style.css` — 화면
- `js/rules.js` — 장기 규칙 (ffish.js: 합법수·장군·외통·빅장·한수쉼·점수)
- `js/engine.js` — 컴퓨터 상대 (Fairy-Stockfish WebAssembly) + 급/단별 수 선택
- `js/levels.js` — 27단계 강도표 (보정 스크립트가 자동 생성)
- `js/app.js` — 게임 진행/화면
- `lib/` — 엔진 파일 (Fairy-Stockfish, GPL-3.0 — `lib/Copying.txt`)

## 급/단 보정 방식
- 한게임 승강급 기준: 18~11급 승률 60%, 10~1급 66%, 1~5단 69%, 6~9단 70%에서 승급
- → "한 단계 위 = 아래 단계를 그 승률로 이기는 실력"으로 정의
- 엔진끼리 대국시켜 강도 곡선을 측정하고, 각 단계 간격을 위 승률(Elo 환산)에 맞춤
- 9단 = 엔진 최고 설정. 탐색량을 시간이 아닌 노드 수로 제한하므로 PC·폰 상관없이 같은 실력
- 측정 스크립트: `calib/` 폴더

## 검증 결과 (확정 레벨끼리 실제 대국)
| 대국 | 판수 | 위 단계 승률 | 한게임 기준 |
|---|---|---|---|
| 15급 vs 16급 | 40 | 67.5% | 60% |
| 6급 vs 7급 | 40 | 72.5% | 66% |
| 2단 vs 1단 | 30 | 75% | 69% |
| 7단 vs 6단 | 12 | 75% | 70% |

모두 기준보다 5~7%p 높게 나왔지만 판수에 따른 오차(±7~12%p) 안입니다. 판수를 늘려 재검증하려면 `calib/calib.py`를 사용하세요.
